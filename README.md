# JNotes

JNotes is a desktop notepad application built with plain Java Swing.

## Run on Windows, Linux, or macOS

From the project root, compile and run with the JDK:

```bash
javac -sourcepath src src/com/notepad/NotepadApplication.java
java -cp src com.notepad.NotepadApplication
```

On Windows Command Prompt, use:

```bat
javac -sourcepath src src\com\notepad\NotepadApplication.java
java -cp src com.notepad.NotepadApplication
```

If you prefer PowerShell, the same commands work with the Windows path separators shown above.
